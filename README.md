# Tuner

An Android application written in sysl, started from
[Skitter](https://github.com/sysl-lang/skitter).

```
skitter run
```

builds it, installs it, launches it and follows the log.

`program/main.sysl` is your program. The two names this project is known by are in
`gradle.properties`, and nothing else in the repository is named for it.
